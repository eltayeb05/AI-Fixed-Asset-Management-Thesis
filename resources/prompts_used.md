# Prompts Used for Prototype Screens

## 1. Asset Depreciation Prediction Input Screen

Design a modern and clean web application input screen for a Fixed Asset Management system.

The purpose of the screen is to allow users to enter asset data in order to predict depreciation using a machine learning model.

Include the following elements:

- Title at the top: "Asset Depreciation Prediction"
- A simple and professional layout (centered form or card style)

Input fields:
- Asset Cost (numeric input)
- Asset Age (numeric input, in years)
- Usage Level (numeric or dropdown: low, medium, high)
- Maintenance Cost (numeric input)
- Asset Type (dropdown: e.g., Machinery, Vehicle, Equipment)

Buttons:
- Primary button: "Predict Depreciation"

Additional UI elements:
- Small helper text under the form: "The system uses a machine learning model to estimate asset value and depreciation."
- Optional icons for each input field (e.g., money, calendar, tools)

Design style:
- Minimal, modern UI
- Soft colors (light background, blue or green accents)
- Clear spacing and readable typography
- Professional look suitable for accounting/business users

Make the layout intuitive and easy to use, with proper alignment and spacing.

## 2. Depreciation Prediction Results Output Screen

Design a modern and clean web application output screen for a Fixed Asset Management system.

The purpose of the screen is to display and allow editing of the results of an asset depreciation prediction generated by a machine learning model.

Layout:
- Use a clean dashboard-style layout with a centered card or panel
- Title at the top: "Depreciation Prediction Results"

Display the following outputs clearly:
1. Predicted Asset Value
2. Depreciation Amount
3. Estimated Maintenance Cost

Each output should:
- Be displayed in separate cards or sections
- Include clear labels and large, readable values
- Be editable

Use example values:
- Predicted Asset Value: 7,500
- Depreciation Amount: 2,500
- Estimated Maintenance Cost: 1,200

Include an additional section titled:
"How the Prediction Works"

Inside this section, display:
- Model Type: Regression-based Machine Learning Model
- Inputs Used: Cost, Age, Usage, Maintenance, Asset Type
- Short explanation: "The model analyzes asset characteristics and historical patterns to estimate current value, depreciation, and expected maintenance cost."

Buttons:
- "Back" or "Edit Input"
- Optional: "Generate Report"

Design style:
- Minimal, modern UI
- Professional look for accounting/business users
- Soft colors
- Clear spacing and alignment
- Dashboard-style presentation
