# Artificial Intelligence in Fixed Asset Management

## Project Overview

This repository contains the bachelor thesis project titled **Artificial Intelligence in Fixed Asset Management**.

The project focuses on designing a prototype system that demonstrates how a regression-based machine learning concept can support fixed asset depreciation prediction. The prototype is designed for accounting and fixed asset management users.

The proposed system allows users to enter asset-related data such as asset cost, asset age, usage level, maintenance information, and asset type. Based on these inputs, the system conceptually supports outputs such as predicted asset value, depreciation amount, and estimated maintenance cost.

The project is represented through prototype screens, BPMN diagrams, a use case diagram, user stories, test cases, field requirements, business rules, and expert evaluation.

---

## Important Note About the Project Code

This project is a **prototype-based thesis project** and not a fully deployed software application.

The machine learning model is presented conceptually using a regression-based approach. No real machine learning model was trained or deployed, and no backend or frontend application was implemented.

Therefore, there is no executable source code required to run the system. The project is demonstrated through Figma prototype screens, diagrams, documentation, and design artifacts.

---

## Project Objectives

The main objectives of this project are:

- To design a prototype that supports fixed asset depreciation prediction.
- To show how machine learning can be conceptually applied to fixed asset management.
- To allow users to enter asset-related data and view depreciation-related outputs.
- To connect technical system design with accounting requirements.
- To improve the prototype based on expert feedback from technical and accounting perspectives.

---

## Research Methodology

This thesis follows the **Design Science Research Methodology (DSRM)**.

The methodology was used to guide the development and evaluation of the proposed prototype through the following phases:

1. Identify the problem and motivation.
2. Define the objectives of the solution.
3. Design and develop the prototype.
4. Demonstrate the prototype using screens, diagrams, user stories, and test cases.
5. Evaluate the prototype through expert feedback.
6. Communicate the final artifact through the thesis and project documentation.
