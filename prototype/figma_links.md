# Figma Prototype Links

This thesis uses Figma prototypes to demonstrate the proposed fixed asset depreciation prediction system.

## 1. Asset Depreciation Prediction Input Screen

Figma Link:  
https://www.figma.com/make/Gy6C0U1dVPS9ddjf6diuYZ/Fixed-Asset-Input-Screen?p=f&t=hcASyYvTi1HgVMyq-0

Purpose:  
This screen allows users to enter fixed asset data such as asset cost, asset age, usage level, maintenance cost, and asset type before starting the depreciation prediction process.

## 2. Depreciation Prediction Results Output Screen

Figma Link:  
https://www.figma.com/make/6ntdgHgR8iBcsd3rXgxXws/Depreciation-Prediction-Results-Screen?p=f&t=98E8wmBpo1s5fKKu-0

Purpose:  
This screen displays the prediction outputs, including predicted asset value, depreciation amount, and estimated maintenance cost.
